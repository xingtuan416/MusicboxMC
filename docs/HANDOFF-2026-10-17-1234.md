## 二、项目是什么

把 MIDI 文件转成 Minecraft 红石音乐投影（`.litematic`）的桌面应用。Electron 33 + TypeScript 5.7（`strict` + `noUncheckedIndexedAccess`），无打包器、无前端框架。

数据流：`MIDI → SongModel → LayoutResult → RegionData[] → .litematic`

**两个播放后端**（这是产品的核心分叉，改动时别只测一个）：

- **红石电路**（默认）：音符盒 + 中继器 + 红石线，真的可以照着搭。
- **命令方块播放**：每音符一条 `playsound`，不受复音与距离限制，但需要区块常驻。

## 三、关键不变量（改动前必须知道）

这些是算法成立的前提，不是风格偏好：

1. **红石线零延迟、只有中继器延迟。** 整个多轨对齐依赖这条：用红石线把轨道在空间上拉长，**音乐时间轴完全不动**。任何"给补齐加中继器"的改动都会毁掉时序。
2. **音符盒正上方必须是空气。** 红石线、中继器、音符盒共享同一层（`circuitY`）。
3. **衰减预算共用。** 分支列强度 = `WIRE_STRENGTH - 末段补齐格数`，分支第 r 行需要剩余 ≥1。所以末段补齐上限是 `WIRE_STRENGTH - 1 - 分支最远行`（见 `src/core/layout/track.ts`）。**这条曾被违反，导致 29 音和弦最外侧 6 个音静默无电。**
4. **量化误差是两次取整。** 秒 → 游戏刻（±½ 刻）→ 红石刻（±1 刻），合计 **±75ms**，不是 25ms。
5. **NBT 字符串是 Java Modified UTF-8**（`DataInput.readUTF`），不是普通 UTF-8。emoji 写成 4 字节会让 Java 拒绝加载。`src/core/nbt/modifiedUtf8.ts` 是唯一实现，别绕过。

## 四、代码结构

```
src/core/        纯逻辑，不依赖 Electron：midi / layout / palette / litematic / nbt / tempo / command
src/main/        主进程：service（编排）、generate（结果组装）、analyze、messages（错误码→中文）、index（窗口与 IPC）
src/preload/     contextBridge，暴露 window.musicbox
src/renderer/    界面：app.js（全部行为）+ preview.js（画布）+ warningText.js（警告文案）+ resourcepack.js
```

**界面是 8 步整屏流程**：开始 → 导入 → 选轨 → 配置 → 导出位置 → **检查结果（空跑找问题）** → 生成 → 完成。

第 6 步和第 7 步的关系是刻意设计的：第 6 步**不传输出路径**调一次生成器（完整算、不写盘），把警告显示出来；用户改完再在第 7 步真正生成。**代价是同一首歌算两遍**——Rush E（46,291 音符）实测 2494ms。这是产品决策，不是 bug。

界面标记与样式是设计师给的，**改动时保持手脚轻**：只在必要处动，不要顺手重构视觉。

## 八、踩过的坑（能省你半天）

- **Prettier 会重排文件**，于是你记忆里的精确文本匹配会失效。改完跑 `npm run format` 之后**重新读**再匹配。
- **改文件用 `ops_replace` 前先确认替换文本里的 `${...}`**：这类工具曾把它当捕获组解释并在替换前抛错，导致我改用脚本打补丁，而脚本自己又删坏过内容（一次删掉大半个 `app.js`，一次删掉一个 `</div>`）。**如果非要用脚本批量改，务必在写盘前校验"改前的每个函数名改后都还在"**——而且这个清单要从文件里读，不能凭记忆列（凭记忆会两头都错）。
- **守卫不要把注释当代码。** 我曾写过 `/minX/.test(file)` 的守卫，它命中了文档注释里的 `-(minX, minY, minZ)`，把正确的修改拦了下来。
- **`ELECTRON_RUN_AS_NODE=1` 在本机环境里是设着的**，它会让 Electron 以普通 Node 运行，`require('electron')` 返回路径字符串（`app` 变 `undefined`）。跑 Electron 脚本前要清掉它。
- **`isVisible()` 抓不到被裁掉的元素**，要比 `getBoundingClientRect()` 与父容器的关系。
- **验证 UI 必须重新 `npm run build`**，否则验证的是旧代码；`out/fresh-dist.cjs` 里有现成的"产物比源码旧就拒绝运行"的守卫。
